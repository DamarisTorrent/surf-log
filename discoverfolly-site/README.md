## Free Hosting Options

You have 3 excellent options for hosting this site **completely free**:

### Option 1: Netlify (RECOMMENDED - Easiest)

**Steps:**
1. Go to [netlify.com](https://netlify.com) and create a free account
2. Click "Add new site" → "Deploy manually"
3. Drag and drop the entire `discoverfolly-site` folder
4. Your site will be live in seconds at a URL like `yoursite.netlify.app`
5. Optional: Connect your own domain (discoverfolly.com) for free

**Pros:**
- Easiest option - just drag and drop
- Automatic HTTPS
- Free custom domain support
- Instant updates when you drag new files

### Option 2: GitHub Pages

**Steps:**
1. Create a free account at [github.com](https://github.com)
2. Create a new repository called `discoverfolly`
3. Upload all the files from the `discoverfolly-site` folder
4. Go to Settings → Pages
5. Enable GitHub Pages from the main branch
6. Your site will be live at `yourusername.github.io/discoverfolly`

**Pros:**
- Version control included
- Free custom domain support
- Good for collaboration

### Option 3: Vercel

**Steps:**
1. Go to [vercel.com](https://vercel.com) and create a free account
2. Click "Add New Project"
3. Upload the `discoverfolly-site` folder
4. Your site will be live instantly

**Pros:**
- Very fast performance
- Automatic HTTPS
- Free custom domain

## Using Your Own Domain

All three hosting options above support using your own domain (discoverfolly.com) **for FREE**:

1. In your domain registrar (where you bought discoverfolly.com), update the DNS settings
2. Add the hosting provider's nameservers or DNS records (they'll provide these)
3. Wait a few hours for DNS to propagate
4. Your site will be live at discoverfolly.com!

## Making Updates

To update your website content:

1. Edit the HTML files in a text editor (VS Code, Sublime Text, or even Notepad)
2. Re-upload to your hosting service
3. Changes go live instantly

### Common Updates:

**Change Text:**
- Open the HTML file in a text editor
- Find the text you want to change
- Edit it and save
- Re-upload

**Change Images:**
- Replace the image URL in the HTML file
- Save and re-upload

**Change Colors:**
- Open `styles.css`
- Find the `:root` section at the top
- Change the color values
- Save and re-upload
